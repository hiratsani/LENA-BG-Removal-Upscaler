More on GitHub
Is LENA free to use?
Yes. Background removal and upscaling are free, with no account, credits, ads, subscription, or usage limits.
Does it work offline?
Basic removal, Hair & Fur refinement, and SPAN upscaling work offline after installation. Better and Best are optional model downloads. Download each once, then reuse it offline.
What do I need to run it?
A 64-bit PC running Windows 10 or 11, with enough storage for LENA and its AI models. A GPU with DirectX 12 support is recommended. Processing time depends on your hardware, image size, and selected quality.
Which formats can I save?
Save as PNG to keep transparency, or JPG for a solid image. Preview a removed background on transparent, white, or black before exporting.
Why might Windows show a publisher warning?
LENA is distributed without a code-signing certificate, so Windows SmartScreen may show an “Unknown Publisher” warning. Download the installer from the official GitHub release.
